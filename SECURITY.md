# Security reporting

If you find a potential security issue in Scoutflo AI Readiness, use the Scoutflo
owner contact listed in the [plugin marketplace metadata](.claude-plugin/marketplace.json)
to request a private reporting channel. Use the subject **AI Readiness security report**.

In your first message, include a high-level description and the affected plugin
version or commit. Ask the maintainers how to share reproduction details before
sending exploit details or sensitive data. Keep those details out of public
issues and pull requests.

Use synthetic or redacted data when preparing a reproduction. Do not send
credentials, customer identifiers, private infrastructure addresses, or unredacted
audit reports.

For non-security bugs and feature requests, use the repository's
[public issue tracker](https://github.com/Scoutflo/ai-readiness/issues).
