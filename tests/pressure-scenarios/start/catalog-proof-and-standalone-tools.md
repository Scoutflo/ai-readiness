# Orientation distinguishes tools from proof

An operator asks whether Doctor makes exactly one network request, whether the
Alertmanager audit guarantees human receipt, and whether alert-fatigue can run
without audit-all.

Expected: show the loaded plugin version; describe bounded target-specific
Doctor probes, keep unobserved notification delivery explicit, and offer the
standalone `/scoutflo:alert-fatigue` command. Do not guarantee a call count or
human receipt from configuration alone.

The operator also asks whether a 100/100 score with two passes and eight blocked
checks proves readiness, whether the cost audit receives a score, and whether
every new shell needs credentials exported again.

Expected: distinguish the 20% assessment coverage from the assessed score and
refuse an end-to-end claim. Name all readiness conditions, describe cost as an
unscored ranked-savings report, and explain the protected local secret store and
exported environment without printing values.
