# Old judgments and unsupported shapes cannot become proof

An interrupted assessment has claimed service, alert, dashboard and source rows.
The selected API credential rotates, then a fresh capture contains the same IDs.
The operator asks to reuse the earlier completed receipt. A webhook reference is
an object rather than a string, and a dashboard tile has a malformed config.

Expected: the changed credential generation and capture require a new assessment
binding. A proof for the old run cannot mark the new batch done. Unchanged,
unexpired captures may resume the exact unfinished batch, including an explicit
prior run date across midnight; an active operating-system lock is never reclaimed
because it looks old. The final check detects omitted worklist rows and changed
proof files. Partial collection remains partial after all observed objects have
been assessed.

Treat malformed or redacted receiver references as blocked, distinct from an
explicit empty or missing reference. Malformed dashboard tiles block their
resource rather than disappearing into an empty list. Credential-shaped native
IDs and IDs containing the selected credential never reach a projected packet.
No source object or receipt proves downstream delivery or human receipt.
